# cs465-fullstack

In this full stack project, I worked with two main approaches: traditional Express HTML and a modern single-page application built in Angular. The Express approach is server-driven, meaning each request results in a full page being rendered and sent back to the browser. This is slower than an SPA, but it has tighter coupling between the front and backend logic. The SPA loads once in the browser and then updates dynamically using API calls without refreshing the page. This makes the application faster and easier to scale in terms of frontend complexity. The backend uses a NoSQL MongoDB database that provides flexibility in handling semi-structured data like trip listings. Unlike relational databases, MongoDB does not require fixed schemas, which makes it easier to evolve the data model as features are added.

JSON is a data format used to exchange data between the frontend and backend. Although it is based on JavaScript syntax, JSON is not executable code; it is purely a data format. JSON acts like a bridge between Angular and Express in this project. Throughout development, I refactored code, particularly the Angular components. For example, I improved the trip data service by centralizing the API calls into reusable functions. I also used reusable UI components such as the trip card, which allowed the same structure to display different trip data dynamically.
